下表对应仓库里现在的文件。测试台能编译，只说明端口接得上，不表示空模块已经有行为。三条根目录脚本和它们仿真层次的对应关系在 xref:tests.adoc[测试脚本]。

|`StandardCell/`

|两相局部控制器，用地址比较结束每一相

== 端口在、行为还没有

[cols="2,3",options="header"]
|===
|模块 |现状

|`st_cross_a`
|端口列出了数据、使能、状态、公式和三路 8 位结果。模块体为空。处理单元已经例化它，三路结果没有驱动。

|`st_node`
|端口是 8 位 `signal_in`、`en`、`signal_out`。模块体为空。

|`st_relation`
|没有端口，模块体为空。

|`st_1_to_4_router`
|四个输出都等于输入，`rst` 未使用。

|`st_2_encoder`
|注释为 WIP。透明锁存把 `req` 变成一对互补 grant。

|`do_BRAMToflash`
|类型 `8'b00000100` 已译码，没有写回模块。

|`st_flash_to_bram` 的 `valid`
|已计算 `memo_valid & req`，没有负载。

|`tb_storage`
|只打开 `tb_core.vcd` 然后结束，没有存储激励。`test_storage_run.bat` 跑的就是这个测试台。
|===

== 清单写了、树里没有

`filelist.f` 还列出这些路径，工作区里没有对应文件：

* `StandardCell/st_delay_line.v`
* `StandardCell/st_reset.v`
* `StandardCell/st_glitch_free_mux.v`
* `StandardCell/st_fifo.v`
* 根目录的 `press.v`

根目录有 `tb_press.v`。没有 `press.v` 时，这个测试台不能按文件清单单独编译。

`GUI/` 下是若干 `.out` 仿真日志，不是时钟无关电路的界面。`CORE/` 下没有 Verilog 源文件。
