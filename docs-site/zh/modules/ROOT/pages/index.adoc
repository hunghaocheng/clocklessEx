= 基于门级网表的无时钟事务驱动图网络
:description: clocklessEx 以事务为运行单位，用节点和关系组织无全局时钟的计算。
:navtitle: 文档库

本项目提出一种事件驱动的无时钟计算架构。事务是基本运行单位，节点和关系构成计算模型。系统靠事件触发、状态判断和关系传播往下运行，不靠一根全局时钟统一调度。

后续事务来自外部输入、节点状态及其关联关系。状态变化、关系匹配和事件传播用门级网表直接实现。

项目要建立的是以事件、因果关系和动态传播为基础的计算体系：硬件根据当前状态自己决定运行方向，并能够分支、汇合、持续传播或终止。

== 从指令驱动转向事务驱动

传统处理器以指令为基本执行单位，用程序计数器和指令译码把计算排成序列。

本项目以事务为基本运行单位。事务由外部事件、节点状态变化或其他关系传播触发，再由当前状态判断要不要产生后续事务。计算过程不再只复现一条固定指令序列，后续方向由事务触发、状态变化和关系条件决定。

电路上，一笔事务的到达和完成用 xref:handshake.adoc[使能、请求与应答] 表示，不靠时钟沿采样。处理单元源码里的注释把同一意图的不同表面形式当成要面对的问题，见 xref:processing.adoc[处理单元]。

== 图网络计算模型

=== 节点与关系

系统以图为基本计算模型，由节点和边组成。节点保存数据、身份和运行状态。边描述节点之间的依赖、关联和传播方向。

节点用固定宽度的二进制结构表示。身份可以由存储地址或映射表确定，上层语义由离线工具完成映射。源码里预留了 `st_node` 和 `st_relation`，模块体目前是空的。

=== 状态判断与关系传播

外部事件触发节点之后，系统按当前状态匹配关联关系，判断有没有有效的后继节点。匹配成功就产生新的事务。存在多条有效关系时做分支或仲裁。不存在有效关系时，结束这一次传播。

因此，后面往哪走，由节点状态和关系条件一起决定，而不是完全依赖一条预先排好的执行路径。这个判断准备放在 `st_cross_a`，它的端口已经列出，模块体仍是空的。

=== 自主传播与收敛

事务根据已有关系和状态变化继续触发后续事务，不需要外部处理器逐条发送执行指令。

传播过程由继续传播、分支、汇合、静默停止和外部输出这些状态来控制。没有有效后继，或者到达指定的输出锚点时，当前事务链路终止。

图网络因此不只存放数据、描述关系，还直接组织硬件上的计算过程。两路事件可以先后到达、到齐才发放的电路，见 xref:neuron.adoc[事务神经元]。

== 和当前电路的对应

上面是项目要建立的计算体系。下面各卷按仓库里已经写下来的源码说明，空模块不会被写成已经完成的功能。

已经接上的是门级网表、局部握手、存储通路和事务神经元。数据何时被收下、地址何时前进，由局部使能和应答决定。仍会出现的重复电平，要么是某一条通路自己的两相控制器，要么是仿真用的环振，不是全芯片共用的时钟。带 `clk_cache` 的 FIFO 只放在同步边界上。节点、关系和交叉模块还没有把图上的传播算出来，见 xref:status.adoc[实现进度]。
