= 没有全局时钟
:description: clocklessEx 用局部握手代替全局同步时钟，以及源码里哪些地方仍然会出现节拍。
:navtitle: 没有全局时钟

同步电路用一根时钟告诉所有寄存器：这一拍的输入现在有效，可以采样。clocklessEx 的主通路不提供这根时钟。一个操作完成与否，由产生它的那一级自己用电平告诉下一级。

== 用完成信号代替时钟沿

源码里反复出现的是这三件事：

* *使能*（`en`、`memo_valid`、`step_req`）表示上游现在允许这一级动作。
* *请求*（`req`）表示这一级已经把数据锁住，下一级可以取。
* *应答*（`ack`）表示下一级已经取走，请求可以撤掉。

锁存器在 `en` 为高时透传，为低时保持。它不是上升沿触发的触发器。因此同一条链上的模块不必处在同一个时间格子里：突触 A 的事件可以先到，突触 B 的事件后到，胞体等到两路记忆都置位才发放。这是 xref:neuron.adoc[事务神经元] 的测试台要演示的时序。

== 局部节拍仍然存在

“没有全局时钟”不等于电路里没有任何相位。下面两处会制造重复的高低电平，但它们的作用范围是一条通路：

`st_local_clk_hs`::
没有时钟端口。它用三只锁存器记住“已启动、第一相完成、第二相完成”，并用地址是否已经等于目标来结束每一相。模块名里的 `clk` 指的是这个局部相位，不是同步时钟。详见 xref:local-time.adoc[局部节拍与步进]。

`st_ring_osc`::
三只反相器首尾相接，仅用于仿真。每一级带一个时间单位的延迟，单位由测试台的 timescale 决定，相关测试台写的是 1ps/1ps。使能关掉时输出为低，避免后级把空闲电平当成节拍。

处理单元的测试台把环振输出接到 `st_flash_to_bram` 的 `memo_valid`。在这个实验里，环振扮演的是“外部来的一串有效脉冲”，仍然不是全设计共用的时钟树。

== 时钟真正出现的地方

`FIFO/FIFO_cache.v` 里的 `async_to_sync_fifo_ctrl` 有 `clk_cache`。它用移位寄存器把异步写请求同步进时钟域，再写入 RAM。这是通向同步世界的边界，不拿来给锁存器、步进器或神经元打拍。说明见 xref:boundary.adoc[同步边界]。

== 现在还不能声称的事

源码是可仿真的门级和连线描述，不是已完成时序收敛的版图。互斥器是组合逻辑，没有亚稳态滤除。环振的周期是仿真延迟，不是硅片上的振荡频率。空着的 `st_node`、`st_relation`、`st_cross_a` 还没有把“图”或“意图”算出来。
