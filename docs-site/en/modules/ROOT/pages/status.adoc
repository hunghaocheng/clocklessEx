= Implementation status
:description: A module list aligned with the current Verilog sources, separating connected logic, placeholders, and missing files.
:navtitle: Implementation status

The tables match the files in the repository now. A testbench that compiles only shows that the ports connect. It does not mean an empty module has behavior. The three root scripts and the simulation hierarchies they correspond to are in xref:tests.adoc[Test scripts].

== Ports exist, behavior does not

[cols="2,3",options="header"]
|===
|Module |Current state

|`st_cross_a`
|The ports list data, enable, state, formula, and three 8-bit results. The body is empty. The processing unit already instantiates it, and the three results are undriven.

|`st_node`
|The ports are 8-bit `signal_in`, `en`, and `signal_out`. The body is empty.

|`st_relation`
|No ports. The body is empty.

|`st_1_to_4_router`
|All four outputs equal the input. `rst` is unused.

|`st_2_encoder`
|The comment says WIP. A transparent latch turns `req` into a complementary grant pair.

|`do_BRAMToflash`
|Type `8'b00000100` is decoded. There is no write-back module.

|`valid` in `st_flash_to_bram`
|`memo_valid & req` is computed and has no load.

|`tb_storage`
|It only opens `tb_core.vcd` and finishes. There is no storage stimulus. `test_storage_run.bat` runs this testbench.
|===

== Named in the list, absent from the tree

`filelist.f` also lists these paths. The working tree has no matching files:

* `StandardCell/st_delay_line.v`
* `StandardCell/st_reset.v`
* `StandardCell/st_glitch_free_mux.v`
* `StandardCell/st_fifo.v`
* `press.v` at the repository root

`tb_press.v` is at the repository root. Without `press.v`, that testbench cannot be compiled from the file list alone.

`GUI/` contains a few `.out` simulation logs. It is not a user interface for the clockless circuits. `CORE/` contains no Verilog sources.
